# LumenTakeOff public case study

A standalone portfolio landing page by Derek French describing product requirements, configuration rules, and AI-assisted delivery.

## Publish

In Settings > Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, then Save.

Expected URL after successful publication: https://dfr3nch.github.io/LumenTakeoff-site/

Static HTML and embedded CSS; no build step, dependencies, API keys, or custom domain required. Edit `index.html` on main to update the page. `.nojekyll` disables Jekyll processing.

This repository contains only the public landing page. Application source is maintained separately.
